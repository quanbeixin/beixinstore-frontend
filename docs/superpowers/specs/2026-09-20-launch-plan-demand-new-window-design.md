# 上线计划表需求详情新窗口打开

## 目标

在上线计划表页面点击需求名称时，在新的浏览器标签页或窗口中打开需求详情，保留当前上线计划表的筛选条件、滚动位置和页面状态。

## 规则

- 仅上线计划表模式生效。
- 需求详情地址使用 `/work-demands/{需求ID}`。
- 使用浏览器 `_blank` 打开，并设置 `noopener,noreferrer`。
- 实际打开为新标签页还是新窗口由用户浏览器设置决定。
- 需求池、我的需求等复用页面继续沿用当前页进入详情的行为。
- 需求名称旁的复制按钮行为保持不变。

## 实现

在需求名称点击处理处根据 `isLaunchPlanPage` 分流：上线计划表调用 `window.open`，其他页面继续调用现有 `openDetailDrawer`。

## 验证

- 上线计划表点击需求名称后打开新页面，原列表不跳转。
- 新页面正确进入对应需求详情。
- 其他需求列表的点击行为不变。
- 前端生产构建通过。
