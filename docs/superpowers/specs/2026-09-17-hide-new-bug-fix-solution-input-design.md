# 新建 Bug 隐藏修复方案输入框

## 目标

Bug 详情页中，当 Bug 当前状态为“新建”（状态码 `NEW`）时，不展示“流转操作”区域内的“修复方案&影响范围”填写框。

## 展示规则

- 状态码为 `NEW`：隐藏“流转操作”中的 `fix_solution` 表单项。
- 其他状态：继续按现有模块权限展示该表单项，现有必填提示和流转校验保持不变。
- 右侧“修复信息”中的“修复方案&影响范围”只读内容继续展示，不受本次改动影响。

## 实现方式

在 `BugDetailPage` 的 React 条件渲染中同时判断模块权限与当前状态，不使用 CSS 隐藏。这样新建状态下字段不会进入页面交互和表单校验范围。

## 验证

- `NEW` 状态详情页不显示填写框，但右侧只读修复信息仍显示。
- 非 `NEW` 状态下填写框展示行为与修改前一致。
- 前端生产构建通过。
